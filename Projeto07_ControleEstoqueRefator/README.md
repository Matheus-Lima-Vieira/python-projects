# 📦 Projeto 07 - Refatoração com Funções

Este projeto é uma evolução do sistema de controle de estoque desenvolvido anteriormente.

O objetivo foi reorganizar todo o código utilizando **funções (`def`)**, separando cada responsabilidade em blocos independentes e tornando a aplicação mais organizada, legível e fácil de manter.

---

## Funcionalidades

- ➕ Adicionar produtos
- 📋 Listar produtos
- 🔍 Buscar produtos
- ✏️ Alterar informações dos produtos
- 🗑️ Remover produtos
- 💰 Calcular o valor individual de cada item
- 📊 Calcular o valor total do estoque

---

## Conceitos praticados

- Criação de funções (`def`)
- Organização e modularização do código
- Reutilização de código
- Estruturas condicionais
- Laços de repetição
- Manipulação de listas
- Validação de entradas
- Expressões regulares (`re`)
- Formatação de valores monetários

## Aprendizados

Durante este projeto pratiquei a refatoração de um programa já funcional, separando cada funcionalidade em funções específicas.

Foi um importante exercício para compreender como organizar melhor um código e preparar a aplicação para futuras expansões.

Esse projeto serviu como base para os próximos passos, onde serão adicionados armazenamento permanente de dados em arquivos e novas melhorias na arquitetura da aplicação.
